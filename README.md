# Grocery Shop Management System

A full-stack web application for managing a grocery store's products, inventory,
suppliers, customers, purchases, sales, billing, expenses, and reporting.

## Tech Stack
- **Backend:** Java 17, Spring Boot, Spring Security (JWT), Spring Data JPA
- **Frontend:** React, Vite, JavaScript
- **Database:** PostgreSQL

## Status
🚧 Under active development.

## Project Structure
- `backend/` — Spring Boot REST API
- `frontend/` — React SPA
- `database/` — SQL schema and seed data
- `docs/` — documentation and screenshots
